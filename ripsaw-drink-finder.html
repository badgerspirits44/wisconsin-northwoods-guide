🍹 Ripsaw Drink Finder

A free Chrome extension for cocktail lovers

Ripsaw Drink Finder brings a searchable cocktail database directly to your browser. Search over 100 cocktail recipes by ingredient, spirit type, or calorie count — perfect for home bartenders and calorie-conscious drinkers.

Features

  • Search by name or ingredient — Type "bourbon" to find every bourbon cocktail, or "lime" for everything citrus
  • Calorie filter — Slide to find drinks under 150 calories, under 200, or any range
  • Spirit filters — Filter by whiskey, vodka, gin, rum, tequila, brandy, or Campari
  • Click to expand — Full ingredient list, instructions, and ABV for each drink
  • Source links — Drinks from borrachos.bar link directly to the full article
  • Wisconsin originals — Signature drinks from Ripsaw Saloon in Prentice, WI

Database

  • 38 original recipes from borrachos.bar
  • 63 classic cocktails (Manhattan, Margarita, Mojito, Negroni, Old Fashioned, and more)
  • Calorie data for 96 of 101 recipes

Install

Install from the Chrome Web Store (search "Ripsaw Drink Finder") or from Firefox Add-ons.

Try the Web App

Use the full version online at borrachos.bar/drink-finder — no install needed.
