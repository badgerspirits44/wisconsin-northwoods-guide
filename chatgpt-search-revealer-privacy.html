Privacy Policy

ChatGPT Search Revealer Browser Extension

Last updated: August 1, 2026

The ChatGPT Search Revealer browser extension ("the extension") is provided at no cost. This privacy policy describes how the extension handles data.

Data Collection

The extension does not collect, store, or transmit any personally identifiable information, health information, financial information, authentication data, personal communications, web history, user activity, or website content.

What the Extension Does

The extension intercepts the streaming response from ChatGPT's /backend-api/conversation endpoint within the user's browser tab. It parses the Server-Sent Events (SSE) stream that ChatGPT is already sending to the user's browser, looking for web search queries, search results, and citations that ChatGPT generates but does not display by default. These are shown in a floating panel overlaid on the ChatGPT page.

All processing happens locally in the browser. No data is sent to any external server.

Data Storage

The extension uses the browser's local storage API to save:

  • Panel state (expanded/collapsed) for the current session
  • Captured search entries for display within the current page session

All stored data remains on the user's device and is cleared when the tab is closed. No data is synced to the cloud or transmitted to any server.

Data Transmission

The extension makes no additional network requests. It only reads the response stream that ChatGPT is already sending to the user's browser. The extension does not transmit any data — not search queries, not results, not user input, not browsing data — to any server. All data stays in the user's browser tab.

Permissions

  • storage — Used to save panel display state locally
  • Content script host permissions (chatgpt.com, chat.openai.com) — The content script runs only on ChatGPT pages to intercept the response stream and display the panel

Third-Party Services

The extension does not use any third-party services. No analytics, no advertising, no tracking SDKs, and no remote data fetching of any kind. The extension does not communicate with any server other than the ChatGPT page the user is already visiting.

Data Sales and Transfers

  • We do not sell or transfer user data to third parties
  • We do not use user data for purposes unrelated to the extension's single purpose (revealing ChatGPT's hidden web searches)
  • We do not use user data to determine creditworthiness or for lending purposes

Children's Privacy

The extension does not collect any data from users, including children under 13.

Changes to This Policy

We may update this privacy policy from time to time. Changes will be posted on this page with an updated revision date.
